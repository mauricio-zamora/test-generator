def convertir_mayusculas(nombres: list[str]) -> list[str]:
    resultado: list[str] = []
    for nombre in nombres
        resultado.append(nombre.upper())
    return resultado

print(convertir_mayusculas(["ana", "luis"]))
¿Qué está mal en el código anterior? Explique la causa exacta del error.
15. El siguiente código pretende contar cuántas veces aparece cada palabra de una lista usando un diccionario. Indique cuál es el error lógico o de sintaxis presente. (8 puntos)
def contar_palabras(palabras: list[str]) -> dict[str, int]:
    conteo: dict[str, int] = {}
    for palabra in palabras:
        if palabra not in conteo:
            conteo[palabra] = 0
        conteo[palabra] = 1
    return conteo

print(contar_palabras(["sol", "luna", "sol"]))
¿Qué está mal en el código anterior? Explique la causa exacta del error.
